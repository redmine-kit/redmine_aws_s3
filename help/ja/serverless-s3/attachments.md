# 添付ファイルの S3

「管理」›「Serverless」›「添付ファイルの S3」には、Redmine が添付ファイルを Amazon S3 にどう置いているかを表示します。プラグインを有効にする「環境変数」(「設定済み」か「未設定」か)、バケットの読み書きと CloudFront からの配信の「確認」、「マルウェアのスキャンで断ったファイル」、添付ファイルとバケットの「突き合わせ」です。

詳しくは [Redmine Serverless S3 の管理画面](https://redmine-kit.github.io/redmine_serverless_s3/ja/admin.html) と [添付ファイル](https://redmine-kit.github.io/redmine_serverless_s3/ja/attachments.html) を参照してください。
