# S3

「管理」›「AWS」›「S3」には、Redmine が添付ファイルを Amazon S3 にどう保存しているかを表示します。プラグインを有効にする「環境変数」(「設定済み」か「未設定」)、バケットの読み書きと CloudFront からの配信の「接続テスト」、「マルウェアスキャンでブロックしたファイル」、添付ファイルとバケットの「整合性チェック」、署名付き URL とローカルキャッシュの「設定」です。

詳しくは [Redmine AWS S3 の管理画面](https://redmine-kit.github.io/redmine_aws_s3/ja/admin.html) と [添付ファイル](https://redmine-kit.github.io/redmine_aws_s3/ja/attachments.html) を参照してください。
